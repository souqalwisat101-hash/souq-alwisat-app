إعداد الخادم
1
تثبيت PHP-FPM على الخادم
sudo apt install php8.2-fpm php8.2-curl php8.2-xml sudo systemctl enable php8.2-fpm sudo systemctl start php8.2-fpm
2
إعداد Nginx لمعالجة PHP
# أضف في إعدادات الموقع: location /app/ { try_files $uri $uri/ /app/index.html; } location ~ /app/\.php$ { fastcgi_pass unix:/run/php/php8.2-fpm.sock; fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name; include fastcgi_params; }
3
إعادة تحميل Nginx
sudo nginx -t && sudo systemctl reload nginx
4
إنشاء مجلد OTP مع صلاحية الكتابة
sudo mkdir -p /tmp/souq_otp sudo chmod 777 /tmp/souq_otp

أسئلة شائعة
❓ هل أحتاج إنترنت لاستخدام التطبيق؟
تحتاج إنترنت لتصفح المنتجات الجديدة وتقديم الطلبات. المنتجات المخزّنة سابقاً تعمل بدون إنترنت.
❓ كيف أدفع إلكترونياً؟
اختر "ثواني للدفع" عند إتمام الطلب ← ستُحوّل لبوابة الدفع ← عند العودة يتم التحقق تلقائياً من حالة الدفع.
❓ كيف أطلب منتجاً؟
أضف المنتجات للسلة ← اضغط "إتمام الطلب" ← اختر الدفع عند الاستلام أو ثواني للدفع الإلكتروني.
❓ لا يظهر خيار التثبيت!
تأكد أنك تستخدم Chrome (أندرويد) أو Safari (آيفون)، وأنك على الرابط souqalwisat.com/app/
❓ هل يحتاج تحديث من المتجر؟
لا! التطبيق يحدّث نفسه تلقائياً من السيرفر عند فتحه.
