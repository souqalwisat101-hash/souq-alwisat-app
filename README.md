# سوق الوساط - مشروع جديد جاهز

هذا مشروع كامل جاهز - احذف المستودع القديم وانشئ مستودع جديد وارفع محتويات هذا الملف.

خطوات الرفع:
1- انشئ مستودع جديد على GitHub
2- ارفع كل محتويات هذا المجلد (lib + assets + pubspec.yaml)
3- اذا طلب GitHub Actions انشاء android مجلد، شغل هذا الامر محليا: flutter create . ثم اعمل commit
4- التطبيق سيبني تلقائيا

المميزات المنجزة:
- شعارك مكبر بدون خلفية بيضاء
- سلايدر عروض من Odoo
- اقسام مع لوجو
- بحث ذكي + بحث بالصورة
- صفحة منتج كاملة + منتجات مشابهة
- فلترة website_published فقط
- شحن: استلام مجاني + شحن مدفوع (1 ر.ع + 0.1 لكل كجم فوق 10)
- مسار: سلة -> شحن -> دفع -> تأكيد
- تسجيل دخول: اسم + هاتف + بريد - يبحث في Odoo اذا موجود
- السلة ثابتة
- الطلب يوصل Odoo sale.order حقيقي
- فوتر كامل
